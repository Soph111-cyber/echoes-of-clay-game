# Echoes of Clay — Reconstructing Ancient Worlds Through Play

An anime-style Streamlit archaeology game that transforms archaeology from static knowledge into interactive systems where users reconstruct history through decisions, uncertainty, and cultural reasoning.

## Modules

1. **Kiln of Identity** — Tang Sancai creation system with identity, glaze, motif, and firing parameters.
2. **Walk the Silk Road** — narrative decision system with cultural transition probabilities.
3. **Ship of Clues** — shipwreck archaeology inference with posterior probability.
4. **Reconstruct the Past** — shard reconstruction and uncertainty explanation.
5. **Flow of Culture** — network diffusion simulator for cultural transmission.
6. **Research Portfolio** — saves gameplay decisions as a research-style archive.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud

- Repository: upload all files and folders, including `data/` and `assets/`.
- Main file path: `app.py`
